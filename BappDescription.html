Request Incubator

Keep HTTP requests alive. Stop when something changes.

Request Incubator is a Burp Suite extension that automatically repeats HTTP requests on a configurable schedule until a user-defined failure condition is met. Automate long-running tests and monitor changes in HTTP responses without manually resending requests.

Features

  • Quick setup: Right-click any request in Burp and select Extensions → Request Incubator → Incubate Request.
  • Flexible scheduling: Send a request once after a delay or repeat it at a regular interval, measured in seconds, minutes, or hours.
  • Custom failure conditions: Stop on 3XX, 4XX, 5XX, any status other than 200, or user-defined text in the response.
  • Dedicated interface: Configure and monitor requests from the Request Incubator tab.
  • Automated monitoring: Continue sending requests until the configured condition is met or execution is stopped manually.

How It Works

  1. Right-click a request and choose Incubate Request.
  2. Open the Request Incubator tab.
  3. Configure the schedule and failure condition.
  4. Start incubation and let the extension monitor responses automatically.

Example Use Cases

  • Session monitoring: Detect expired sessions or lost authorization.
  • Rate-limit testing: Stop when the server returns an error such as 429.
  • Token validation: Detect application messages such as Invalid token or Session expired.
  • State-change detection: Monitor an endpoint until its status code or response content changes.
